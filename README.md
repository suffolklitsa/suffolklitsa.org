# suffolklitsa.org

The website of the Legal Innovation and Technology Student Association at Suffolk University Law School:
Boston legal tech events, competitions, news and resources for Suffolk students. Live at
[suffolklitsa.org](https://suffolklitsa.org).

It's a static site generated by Python. Read [`DESIGN.md`](DESIGN.md) before changing the look.

## Build it

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python build.py
```

The site lands in `build/`. Open `build/index.html`, or serve it with `python3 -m http.server -d build`.

## How it's organized

| Folder | What's in it |
| --- | --- |
| `src/` | One Python file per page (`page_*.py`), plus the shared page shell and data loaders |
| `content/` | The data pages are built from: events, competitions, courses, news, resources |
| `static/` | CSS, fonts, images, files and the `_redirects` short links (like `/rsvp`) |
| `harvest/` | Scripts that refresh `content/` from outside sources, and the scheduled refresh jobs |
| `functions/` | Cloudflare Pages functions (tracked newsletter links) |
| `vendor/` | The LITSA logo geometry and field taxonomy, copied in so the site builds on its own |

## How changes go live

Open a pull request against `main`. Once it's merged, the next scheduled refresh (6:30am and 4:30pm Eastern)
pulls `main`, rebuilds and deploys to Cloudflare Pages. The same job saves refreshed `content/` back to this
repository, so expect commits titled `content: scheduled refresh`.
